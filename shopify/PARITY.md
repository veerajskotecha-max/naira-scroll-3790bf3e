# Port parity scoreboard

Generated by `harness/styledif.mjs`, which loads the real React build and the
rendered Liquid theme side by side, keys every text-bearing element by its own
text, and reports what each side renders that the other does not plus the
computed properties that diverge.

Reproduce with:

    node /tmp/.../harness/spa.mjs            # serves dist/ with SPA fallback on 4325
    THEME_DIR=shopify/theme node render.mjs  # renders every template
    node serve.mjs                           # serves the render on 4310
    REACT_BASE=http://127.0.0.1:4325 bash harness/difall.sh
